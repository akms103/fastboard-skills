# Формат colors.json и формы цветовых ссылок

## colors.json — реестр групп цветов

Массив групп; у каждого цвета — HSL (для пикера), hex (для человека), имя и прозрачность:

```json
[
  {
    "id": "<uuid v4 группы>",
    "name": "Газпром",
    "colors": [
      {
        "h": 203, "l": 38, "s": 100,
        "id": "<uuid v4 цвета>",
        "hex": "#0079c2",
        "name": "Газпром синий (Pantone 300 CV)",
        "opacity": 100
      }
    ]
  }
]
```

`h` 0–360, `l` и `s` 0–100, `opacity` 0–100. Группу создаёт `scripts/add_palette.py`
(hex-first: `"#0079c2:имя:opacity"` — HSL считается из hex).

**Открытый вопрос, проверяемый только на проекте:** читает ли платформа этот файл сама или он
служит реестром, из которого id переносятся в проект. Группа, созданная локально, на живом
импорте отрисовалась, но это не доказывает, что файл читается платформой: страница могла
получить цвета из самой ссылки.

## Две формы ссылок — не путать

Ключ словаря — **id палитры** (`paletteId`), не id страницы и не id группы:

```json
// 1. конкретный цвет из группы: серии, фоны, подписи значений
"elementColor": {
  "<paletteId>": {"type": "color", "groupId": "<группа>", "colorId": "<цвет>"}
}

// 2. группа целиком: категории разреза, фон — цвета берутся из группы по порядку
"elementColor": {
  "<paletteId>": {"type": "palette", "groupId": "<группа>"}
}

// 3. уровень темы: только тексты и системные элементы, палитра тут не участвует
"fontColor": {
  "<pageId>": {"type": "color", "level": 1}
}
```

Пример из боевого файла:

```json
"elementColor": {
  "55f43476-1cd1-11ee-b2df-04d4c47aef75": {
    "type": "color",
    "colorId": "a0cce0d9-2294-44bb-bede-54a4f996d31a",
    "groupId": "27b2fbb6-135b-4d30-be71-fbd949c0e437"
  }
}
```

## Разрез: две формы, зависит от виджета

| форма | где | применение |
|---|---|---|
| ссылка на группу `{type:"palette", groupId}` в `colorBySettingsElement.elementColor` | `incisions[]`, любые графики | ось по месяцам, категории, дирекции: цвет выдаётся из группы по порядку |
| массив `[{"value": "К1", "colorId": …, "groupId": …}, …]` в `incisions[].colors` | сегменты круговой, фиксированные категории | каждому значению — свой цвет |

Обе формы кладутся в один и тот же ключ `incisions[].colors`/`colorBySettings*`, но по-разному
читаются платформой. Для оси времени массив значений означает «каждый месяц своим цветом» —
обычно это шум; для круговой — норма.

## Уровни темы — отдельный механизм

Тексты (заголовки, подписи осей, легенда, значения) красятся уровнями 1–5, а не палитрой.
Что означает уровень, знает платформа, а не файл: в файле лежит только ссылка. В боевых
выгрузках встречаются **оба** варианта ключа — id страницы и id палитры; какой принят вашей
версией платформы, проверяется импортом. Держите ключ одной константой, чтобы развернуть правкой.

Альтернатива без палитры вообще: если проекта-палитры нет, роли текстов остаются уровнями,
а палитровые роли (`series_*`, фоны, разрез) — не заполняются; страница будет в нейтральной
теме, и это валидное состояние.
