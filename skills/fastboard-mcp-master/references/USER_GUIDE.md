# Fastboard по MCP: инструкция для пользователя «с нуля»

Две части: **подготовка данных** (что прислать нейросети) и **передача инструкции**. Дальше нейросеть подключается и работает сама.

## Шаг 1. Соберите данные
1. **BASE_URL** — адрес окружения Fastboard, обычно `https://<хост>.fastboard.online/back`. Пример: `https://dev.fastboard.online/back`.
2. **PROJECT_ID** — id борда. Откройте дашборд в браузере: в адресе `https://<host>/<PROJECT_ID>/board/<pageId>` берите первую hex-группу. Пример: `01234567-89ab-cdef-0123-456789abcdef`. (Это сам проект/борд, не страница.)
3. **PAT_TOKEN** — личный токен проекта, начинается с `fbpat_`. Где взять: в настройках проекта / через API (ручка, отдающая MCP-токен по id проекта), либо выписать из UI, если есть палитра/токены.
4. **pageId** (если нужно править конкретную страницу) — та же вторая hex-группа из URL.
5. **Эталонная выгрузка** (по желанию, для типов виджетов-доноров): экспортируйте существующую страницу (`Импорт → Экспорт`) и положите `*.json` рядом с чатом как образец.
6. **colors.json** (если нужна палитра): файл с группами цветов (`[{id,name,colors:[{h,l,s,id,hex,name,opacity}]}]`). Прислать нейросети.

Токены и URL — секреты: пересылайте в безопасный канал; после работы их стоит перевыпустить.

## Шаг 2. Передайте нейросети сообщение
Вставьте инструкцию ниже и добавьте к ней вот это:

> Мой Fastboard:
> - BASE_URL = `<BASE_URL>`
> - PROJECT_ID = `<PROJECT_ID>`
> - PAT_TOKEN = `<PAT_TOKEN>`
> - pageId (если нужно) = `<pageId>`
> - [если есть] эталонная страница: `<имя файла>`
> - [если есть] colors.json: `<имя файла>`
>
> Задача: [например — добавить группу цветов «Х» из colors.json в палитру проекта и импортировать страницу `имя.page.json` рядом с существующими; не перетирать существующие страницы; подтвердить результат чтением].

## Шаг 3 (инструкция нейросети — вставьте целиком)
> Подключись к MCP Fastboard по данным выше:
> - адрес: `POST <BASE_URL>/api/v3/mcp`, заголовок `Authorization: Bearer <PAT_TOKEN>` (JWT не нужен);
> - JSON-RPC: `initialize` → `tools/list` → `tools/call`;
> - файлы в `tools/call` клади **только** в `arguments.file` объектом `{ contentType, encoding: "base64", data }`, где `data` — чистый base64 без `data:`-префикса;
> - `newPages`/`importModels`/`replaceColors` — строки `"true"`/`"false"`;
> - перед любой записью вызывай `get_last_settings_timestamp({projectId})`;
> - для палитры используй `import_palette_groups {projectId, file, replaceColors:"false"}` или `save_project_palettes {projectId, projectPalettes:[…]}`, для чтения — `get_project_palettes`;
> - для страницы — `import_project_pages {projectId, newPages:"true", importModels:"false", file}`;
> - подтверждай результат: после записи перечитай `get_project_pages` / `get_project_palettes` и покажи, что объект появился;
> - про правила и типовые ошибки смотри приложенный скилл `fastboard-mcp-master`.

## Шаг 4. Проверка
- Появилось ли то, что запрашивали (страница в списке борда, группа в палитре).
- Если «файла нет» ошибка — нейросеть не по тем данным, попросите свериться со скиллом.
- Если что-то не отрисовалось цветом — проверьте, что активная тема ссылается на палитру «Моя палитра 1».
